# 🍫 Feastables Clone

A visually rich and interactive clone of the official Feastables website, built to replicate its modern UI, smooth animations, and responsive design using frontend technologies.

---

## 🚀 Live Demo
👉 https://feastables-clone.vercel.app/

---

## 📌 Overview

This project is a front-end clone of the **Feastables** website.  
The goal was to recreate its **UI/UX, animations, layout structure, and responsiveness** as closely as possible while maintaining clean and scalable code.

---

## ✨ Features

- 🎨 Pixel-inspired UI similar to the original site  
- ⚡ Smooth scrolling and transitions  
- 📱 Fully responsive design (mobile + desktop)  
- 🧩 Component-based architecture  
- 🖱️ Interactive hover effects and animations  
- 🧭 Sticky navigation bar  
- 🎯 Clean layout with modern design principles  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 / Tailwind CSS  
- JavaScript (ES6+)  
- React.js *(if used)*  
- Vite / CRA *(depending on your setup)*

---

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/mahithchenna-ai/feastables-clone.git

# Navigate into the project folder
cd feastables-clone

# Install dependencies
npm install

# Start development server
npm run dev
```
